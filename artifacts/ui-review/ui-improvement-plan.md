# 民大助手界面评审与改进方案

## 结论

当前问题主要来自信息层级、布局占位和异步状态三处，而非单纯配色：

1. 首页把 12 个服务做成等权方块，并放在今日课程之前，高频任务被入口淹没。
2. 浮动底栏叠在正文上，首页和课表都出现内容被遮挡。
3. 课表在约 393dp 宽的设备上仍固定显示 7 列，每列约 51dp；课程名、教师和教室同时塞入后逐字换行。
4. 初次加载只有居中转圈，失败时又同时出现空数据、占位提示和模态弹窗，用户无法判断页面是否可信。
5. 底层英文错误直接展示，且所有错误都用必须确认的弹窗打断。

实测设备为 1080×2400、440dpi，等效宽度约 393dp；系统 `font_scale=1.0`，应用页面缩放约 1.0。也就是说，当前截图中的问题在默认字号下已经存在，大字号会进一步放大。

参考项目中值得吸收的做法：

- One-BNU：首页先放今日时间轴，再放可折叠、可固定的校园服务；导航真实预留底部空间；按宽度切换宫格列数和导航形态。
- Schedule：把“今日”作为独立一级任务；周视图只保留课名和地点，使用省略号控制行数。
- Atori：底部导航由 `Scaffold` 承担布局；课表颜色柔和，详情从格子移到点击后的页面。
- 微北洋：采用模块化、缓存响应式数据流，适合借鉴“先显示缓存，再后台刷新”的状态模型。

## P0：先修复可用性阻塞

### 1. 底部导航不再覆盖正文

- `MainShell.kt` 改为由外层 `Scaffold(bottomBar = ...)` 管理导航。
- 浮动/玻璃样式可以保留，但正文必须预留“底栏实测高度 + 系统导航栏 inset”。
- 普通底栏作为默认样式；浮动样式只改变视觉，不改变布局占位。
- 删除各页面手工补 `96.dp` 的方式，统一从 shell 下发 content padding。

### 2. 课表按可用宽度切换视图

- 提供“日 / 周 / 列表”三种视图并记住用户选择。
- 自动模式：列宽小于 56dp 或 `fontScale >= 1.25` 时进入日视图；用户仍可手动切回周视图。
- 周视图中的课名最多 2–3 行并省略；教师不在格子中显示，教室仅在高度足够时显示一行，完整信息点击后查看。
- 不再为了塞下全部文字把字号缩到 8.5sp，也不允许一个汉字占一行连续排满整个课程块。
- 课程块改为低饱和底色 + 深色文字，当前课程用描边或强调条表示。

### 3. 统一加载、刷新、空和错误状态

建立统一页面状态：`InitialLoading / Content / Refreshing / Empty / Error / StaleContent`。

- 初次加载：显示与真实卡片结构一致的骨架屏，避免整页空白。
- 有内容时刷新：保留内容，只在顶部显示小型进度提示。
- 无内容且失败：页内错误卡，包含中文解释与“重试”。
- 有旧内容且失败：保留旧内容，显示“正在显示上次成功数据，更新失败”。
- 只在提交、删除等需要用户确认的操作中使用模态弹窗；读取失败使用页内提示或 Snackbar。
- `publicError` 把超时、断网、登录失效、服务时间限制映射为用户能执行的中文提示；原始技术信息只写日志/网络诊断。

请销假页面还应保存最近一次成功快照及更新时间。离线时可以查看历史，但申请和销假提交前必须重新在线校验。

## P1：重做首页层级和表单体验

### 首页

- 把“今日课程/下一节课”移到服务入口之前。
- 顶部身份卡缩短，保留姓名、周次、日期；下一节课直接成为主要内容。
- 服务格取消 `aspectRatio(1f)`，改为约 72–80dp 高的小入口；393dp 宽默认 4 列。
- 默认入口最多两行，提供“全部服务”和入口管理。
- 首页使用 `LazyColumn`，避免一次性组合全部内容，并统一处理底部 padding。

### 请假、销假与其他长表单

- 使用分组和渐进披露：先时间与类型，再按规则出现地址、定位、自拍等字段。
- 主要操作放到固定底部操作栏，处理系统导航栏和键盘 inset。
- 校验错误紧邻字段显示；提交前的确认页只汇总关键信息。
- 失败后保留用户已填写内容，不把用户退回空表单。

## P2：建立响应式与视觉规范

- 新增统一 `LayoutProfile`：窗口宽度、高度、方向、`fontScale`、内容最大宽度、服务列数、课表模式。
- 间距只使用 4/8/12/16/24dp；常规卡片圆角统一；减少“每一块都很大、都很圆”的视觉重量。
- 使用主题 typography，减少页面内散落的硬编码 `sp`。
- 平板/横屏切换侧边导航并限制正文最大宽度。
- 动效只用于切周、展开服务和刷新反馈，避免玻璃、模糊与浮动效果影响可读性。

## 建议改动范围

- 导航与 inset：`ui/shell/MainShell.kt`、`LiquidGlassBar.kt`
- 首页：`ui/home/HomeScreen.kt`
- 课表：`ui/schedule/ScheduleScreen.kt`、`CourseTable.kt`、`ScheduleList.kt`
- 通用状态：`ui/common/FeatureUi.kt`、`FeatureNoticeHost.kt`、`FeatureNotices.kt`
- 错误转换和快照：`data/session/Session.kt`
- 请销假：`ui/leave/LeaveScreen.kt`、`LeaveApplyScreen.kt`、`LeaveCancelScreen.kt`
- 响应式规则：新增 `ui/theme/LayoutProfile.kt`

## 验收标准

1. 360/393/411/600dp 宽度均无横向溢出。
2. `fontScale` 1.0、1.3、1.5 下，标题和按钮不被截断，课名不逐字纵排。
3. 任意页面最后一个可操作项都能完整滚到导航栏上方。
4. 刷新失败时已有内容不消失；初次失败时只出现一个明确的页内状态。
5. 用户界面不出现 `Failed to fetch`、异常类名或堆栈信息。
6. 所有主要触摸目标至少 48dp，TalkBack 能读出图标用途和当前选中状态。
7. 为 360×800、393×873、411×891 建立截图回归，覆盖默认字号与 1.3/1.5 字号。
