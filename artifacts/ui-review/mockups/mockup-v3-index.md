# 民大助手 UI V3 全界面设计稿

设计方向：原生校园工具风格，固定四栏底部导航，单一民大红品牌色，减少装饰和独立卡片。

共覆盖 27 个实际页面、1 个课表列表形态、头像裁剪/启动/更新浮层，以及 4 类通用状态。
